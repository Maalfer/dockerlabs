1/8

¿Qué es DockerLabs?

Una plataforma para aprender y practicar hacking ético. Cada máquina es un laboratorio vulnerable a propósito que despliegas en tu propio ordenador con Docker, en segundos y sin máquinas virtuales pesadas.

  • Laboratorios creados por la comunidad, de Muy fácil a Difícil.
  • Todo corre en local: legal, seguro y controlado.
  • Cada máquina tiene writeups para aprender de cómo se resolvió.

¿Para qué sirve?

Para entrenar como en una auditoría real. En cada máquina tienes dos objetivos:

  1. 1
    Intrusión: encontrar una vulnerabilidad y conseguir acceso a la máquina.
  2. 2
    Escalada de privilegios: pasar de usuario normal a root.

Lo que aprendas aquí, úsalo solo en sistemas propios o con autorización.

Lo que necesitas

Un Linux (Kali, Parrot, Ubuntu…) con Docker instalado. En Debian, Kali o Ubuntu:

sudo apt install docker.io

¿No lo tienes? Tranquilo: el script auto_deploy.sh detecta si falta Docker y lo instala por ti. Las máquinas Windows se descargan como .ova y se importan en VirtualBox.

Elige tu primera máquina

  • Abre el filtro Dificultad (justo al lado de este botón de ayuda) y elige Muy fácil.
  • Pulsa Descripción para ver de qué va cada máquina.
  • También puedes buscar por nombre o filtrar por categoría y plataforma.

Descárgala

Pulsa el botón de la máquina. Te llevará a su página de descarga, con las instrucciones.

Descomprime el .zip: dentro encontrarás maquina.tar y el script auto_deploy.sh.

unzip maquina.zip

Despliégala

Abre una terminal en esa carpeta y ejecuta:

sudo bash auto_deploy.sh maquina.tar

En unos segundos el script te dará la IP de la máquina (normalmente 172.17.0.2). ¡Ya puedes empezar!

Cuando termines, pulsa Ctrl + C en esa misma terminal y la máquina se elimina sola.

¡A hackear!

Empieza escaneando la IP para ver qué servicios tiene abiertos:

nmap -p- --open -sV <IP>

Investiga cada servicio, encuentra la vulnerabilidad, entra en la máquina y escala privilegios hasta ser root.
