🧭 Cómo desplegar la máquina
{% if maquina.sistema_operativo == 'virtualbox' %}
  1. La máquina se descarga en formato .zip. Haz clic derecho sobre el archivo y pulsa Extraer todo… para descomprimirlo.
  2. Dentro de la carpeta extraída encontrarás el archivo .ova de la máquina. Haz clic derecho sobre él → Abrir con → VirtualBox Manager: así se importa automáticamente.
  3. Cuando termine de importarse, selecciónala en el listado de VirtualBox y pulsa Configuración.
  4. Ve a la pestaña Red, marca Habilitar adaptador de red y cambia el modo a Adaptador puente: así la máquina obtendrá una IP en tu propia red y podrás acceder a ella.
  5. Guarda los cambios e inicia la máquina. ¡Ya puedes empezar a hackearla!

Necesitas tener VirtualBox instalado. El disco de estas máquinas suele pesar varios GB, así que la importación puede tardar unos minutos.

{% else %}
  1. Abre una terminal en la carpeta donde has extraído el archivo {{ maquina.nombre }}.zip y ejecuta:
    sudo bash auto_deploy.sh {{ maquina.nombre }}.tar
  2. En unos segundos el script te dará la IP de la máquina. ¡Ya puedes empezar a hackearla!

Para eliminar la máquina cuando termines, pulsa Ctrl+C en esa misma terminal.

{% endif %}
